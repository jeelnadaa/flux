Linux

Source & Makefile

Build directly from source with a single command. Statically links the Rust audio engine with native Linux audio backends.

# Clone and build native binary
git clone https://github.com/solarquack/flux.git
cd flux
make
# Run native executable
./bin/flux
  • PipeWire, JACK & ALSA native audio drivers
  • Pure native Rust DSP engine with AVX2 / SSE4.1
  • Zero external runtime dependencies

Engineering Principles

100% Native Architecture

Every audio frame is calculated by native C++/Rust DSP kernels running directly on the hardware with zero browser sandbox overhead.

Air-Gapped Privacy

Zero telemetry, no forced sign-ins, and no tracking. Your audio never leaves your machine unless you explicitly opt in.

Bit-Exact Reliability

What you hear is bit-for-bit what you export. Undo any edit at any time with an immutable, append-only project journal.

Binaural 3D & 8D Sound Stage

Spherical head acoustic simulation, custom room resonance modeling, and multi-dimensional motion path generation.
